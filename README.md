#공고분석기
공고분석기는 클로드를 사용해 바이브 코딩했습니다.
프롬프트 도움은 챗지피티를 이용했습니다. 
### 소개
채용 공고 내용을 입력하면 자주 등장하는 기술 및 역량 키워드를 분석하는 프로그램입니다.

### 기능
- 공고 내용 입력
- 주요 키워드 추출
- 키워드 등장 횟수 확인
- 요구 역량 확인

### 사용 기술
- HTML
- JavaScript
- 바이브 코딩

#학점계산기
그동안 수업에서 배운 걸 통해 학점 계산기 프로젝트를 직접 구현하고 테스트했습니다.
개발 과정에서 인터넷 자료나 AI를 참고해 일부 기능을 보완했습니다.
## 기능
- 과목 추가
- 과목 삭제
- 평균 평점 계산
